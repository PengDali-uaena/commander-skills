# Handoff 字段

字段名、顺序、标题固定，必须输出全部字段，禁止缩成摘要。

```markdown
# Handoff
目标：<一句话结果>
仓库：<绝对路径>
约束：<必须遵守的限制>
禁止：<不要做的事>
文件：
- `<相对路径>`：<这个文件要变成什么样>
步骤：
1. <祈使句，一个动作>。改完结果：<可观察结果>
验收：
- 运行 `<命令>`，预期：<结果>
未决：无
```

没有额外限制时，「约束」写：只改下列文件，写法与这些文件现有代码一致。

没有验收命令时，先问用户用什么命令。用户明确不要命令时写：

```markdown
验收：
- 无命令。人工确认：<可观察结果>
```
