# session-handoff

把这段对话交给另一个看不到本对话的 agent。压缩的是篇幅，不是事实。不改代码。默认只作为回复；用户要求落文件时再写文件。

## 写法

- 下面每类都要出现。没有内容就写 `未提及`，不编造。
- 一条事实一行。来源写在行内：`用户原话`、`文件路径` 或 `日志`。
- 路径、数字、Tag、报错、命令、筛选语句按原文抄写。
- 不使用「等等」「相关逻辑」代替具体符号。写不下就加行，不合并。

## 可见回复

整段回复就是交接，不用代码围栏，块外不加导语。行可以重复。

```
- 目标：一句话结果
- 背景：为什么做。来源
- 已确认：事实。来源
- 已排除：被否定的判断。来源
- 决定：定了什么。谁定的
- 未决：还没定的事
- 原文：报错、Tag、筛选、命令或关键原句
- 下一步：接手方的第一个动作
```
