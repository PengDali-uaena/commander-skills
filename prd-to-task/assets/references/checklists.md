# 必填表清单（prd-to-task 附属）

主文件只在需要填某张表时才读本文件对应小节。表头照抄，缺表或缺列 `validate_task_doc.py` 直接 FAIL。

判据一句话：**视觉写满了不等于状态写清了**。单选、多选、互斥组、开关、提交按钮都要有前三张表；每个接口（含嵌套在卡片里的接口）都要有第四张表；任何图标 / 图片过第五张；任何后端状态字段过第六张；有 Figma 稿的过 6b；任何有写操作的接口过第七张；任何跨端传递或拼 URL 的 id 过第八张；任何会重复触发的请求过第九张；任何等外部回调的链路过第十张；任何本次新增、会被多处引用的常量 / 解析器 / 工厂过第十一张。

---

## 1. 交互状态矩阵

| 控件 | 类型 | 点击瞬间 | 回包前 | 回包后 | 失败 / 超限 | 重复点已选项 |

- **点击瞬间**：乐观选中（立刻变色）还是等接口。若等接口，必须写清「点了看起来没反应」时靠什么告知已收到（按压态 / loading / 全组禁用）。
- **回包前**：能否再点其他选项、能否滚走、服务端数据此刻是否可被覆盖。
- **回包后**：回显取值以接口为准还是保留本地；返回的选中集与本地不一致时按哪边渲染。
- **失败 / 超限**：回滚到哪一版（点击前 / 上次成功），弹什么 toast，文案 key 是什么。
- **重复点已选项**：发请求 / 本地拦 / 取消选中，三选一写死；单选组点已选项等不等同取消，也要写。
- **多选**：有没上限、有没全选 / 清空、被拒后已选是否保留。
- **切组联动**：换档位、换 tab、换筛选时，另一组已选是清空还是保留。

## 2. 权限与容量字段两态

| 字段 | 来源接口 | 为 false / 用尽时 UI | 还敢点时的反馈 |

- 后端下发的 `permissions` / `can_*` / `*_limit` / `*_count` / `expired` / `status` 一律不能写成「仅作参考」。
- 「还敢点」必须给结论：静默不响应 / 弹提示（文案 key）/ 照发请求交给后端拒。
- 本地锁与后端拒绝的反馈要一致：不能一处置灰、一处静默，也不能本地拦了却不给提示。
- 客户端自行推导的锁定态（按 count 与 limit 算出来的）要写清推导规则，以及接口没传时的默认值。

## 3. 后端枚举与未知值

| 字段 | 取值 | 未知值处理 |

- 未知枚举默认**丢弃或只读**；禁止兜底成业务有效值（脏数据会冒充正常选择，图标、高亮、提交值全错）。
- 客户端硬编码映射的（图标、颜色、埋点参数）另写一句：后端新增取值时客户端表现成什么样。
- PRD 或方案若假设「枚举只会合并不会新增」，把它记进「风险与依赖」，不当作已知事实。

## 4. 接口失败与降级

| 接口 | 失败落点 | 展示文案（key） | 重试方式 | 重试后刷新范围 |

- **失败落点**：整页错误页 / 区块错误 / 卡片内区域错误 / 单字段降级默认值，四选一写死。默认不允许「接口失败就整页报错」。
- **展示文案**：主文案 + 副文案各自的 l10n key；失败瞬间先显示什么（骨架 / 旧缓存 / 占位图）也写一句。
- **重试方式**：入口在卡片内还是整页；retry 期间是骨架 / 按钮 loading / 全组件禁用；防连点（单飞 + 最短间隔）；重试次数上限与耗尽后的兜底。
- **重试后刷新范围**：只刷该卡片 / 刷整页 / 回列表；成功后是否清失败缓存、是否顺带刷新依赖它的字段。
- **自动重试**：下拉刷新、页面重新可见、网络恢复时是否自动重发，写一条；不写就是不做。
- **空 vs 失败**：200 + 空数据是空态，不是失败态。
- **业务错误码不走 retry**：无权限、已删除、已下架给降级或跳转路径。
- **抖动阈值**：慢网络下多久才显示失败态，写毫秒或写「不延迟」。

## 5. UI 资产与图标

| 控件 / 区域 | 复用组件（文件或类名） | 图标 / 图片 | 来源（node / 现有 asset / 需新增） | 导出方式 | 尺寸与主题适配 |

- **来源只能三选一**：Figma 图标（node-id）/ 仓库现有 asset 或 iconfont（文件:行）/ 需新增（格式、命名、尺寸）。三样都没有就 `待定（缺图标来源）`。
- **导出方式只能二选一**：`SVG` / `PNG rawImages@3x`，且必须是按主文件 workflow 比过体积的结果。写 `export` 一律 FAIL。
- **验收给实际结果，不写形容词**：贴 `check_assets.sh` 的输出（mode / hasAlpha / 像素 / 体积），不写「已压缩」「透明底」。
- **禁止**「用相近图标代替」「从网上下一个」「先放个占位」，也不许自己命名后让开发去猜。
- 图标的选中态 / 禁用态 / 深浅色主题适配写在同一行；只给默认态不算完。
- 复用组件必须写清现有文件与类名；本次新写的组件与每个新增资源文件都要在「改动边界」表单列 `新增` 行。

## 6. 状态 → 视觉映射

| 后端字段 | 取值（全部枚举） | 视觉（色值 / 图标 / 文案 key） | 可点性 | 上报 |

- **列全已知取值**，一行一个；必须覆盖 Loading、空、失败、无权限、已过期这类非正常态。
- **未知值 / null / 缺字段单独一行**，写「丢弃或只读」+ 具体表现。
- **禁止把未知值或未确认的取值兜底成业务有效态**；取值清单没拿到就 `待定（缺后端枚举，阻塞联调）`。
- 客户端自己推导的状态（按 count 与 limit 算出的锁定态）写清推导规则与缺字段时的默认表现。

## 6b. 视觉规格（逐区块，Figma 稿必填）

| 区块 | Figma node | 文字（字号 / 行高 / 字重 / 色值） | 尺寸与圆角 | 内外间距 | 资源逻辑尺寸 |

- **只写 node 链接不等于写了规格**：链接解决「去哪看」，表解决「是多少」。留到实现期再取 = 文档缺陷（2026-11 评论填写页：五档行锚了 node，其余区块只有文字清单，实现直接吃 Flutter 默认值——提示文字 16sp 深色、示例缩略图 67 而稿上 154、顶栏叠出黑底）。
- **逐区块 = 逐可见块**：页顶栏、状态栏、每张卡片容器、每段文案、每个输入框、每个缩略图与按钮各占一行；圆角 / 底色 / 内距写在容器行，不留给子元素猜。
- **图层结构照抄**：node 里是白卡的，写成白卡 + 圆角 + 内距，不压扁成「平铺一行」。
- **透明态写清垫底**：顶栏 0% 不透明、状态栏透明这类写法，必须写明底下垫的是整页渐变还是实色，否则实现会叠在透明 `Scaffold` 上出黑底。

**默认值禁用（每条都对应一种「文档看着齐、实现却走样」）**：

| 控件 | 必须写全 | 禁止 |
|---|---|---|
| 输入框 / 文本域 | 字号 / 行高 / 提示色 / 框高 / 底色 / 圆角 / 内距 | 只给 hintText key，让实现吃 `TextField` 默认 style |
| 卡片 / 分区容器 | 底色 / 圆角 / 内距 / 块间距 | 只写「白卡 A、白卡 B」 |
| 缩略图 / 示例图 / 加图块 | 逻辑尺寸 / 圆角 / 描边（含是否虚线）/ 角标尺寸 | 目测一个数；与「资源落盘清单」的逻辑尺寸对不上 |
| 页顶栏 / 导航栏 | 底色（实色或透明）/ 标题字号与色值 / 返回图标色 | 只写「不透明度 0→100%」 |
| 档名 / 角标 / 按钮文案 | 单行是否允许省略、列宽是否允许溢出 | 一律 `Expanded` + `ellipsis`，把 Dissatisfied 截成 Dissatisfi… |

## 7. 部分回包与字段缺失

| 接口 | 回包字段组合 | 缺失字段处理 | 是否允许覆盖本地新值 |

- 至少列「只带 A 不带 B」与「只带 B 不带 A」两种组合，没有这行就默认按整包替换实现，会丢掉刚拿到的新权限。
- **解析顺序**：先合并 `permissions` / 状态字段，再判业务字段；禁止因为业务字段缺失就整包 `return` 原对象。
- **覆盖判定**：写清「回包版本 / 更新时刻 < 本地」时丢弃，还是以回包为准。
- **列表与缓存同步**：单条更新后是否回写列表、是否重排、是否失效上级缓存。

## 8. 标识与外部输入

| 标识 / 输入 | 来源字段（发送侧） | 接收侧同一个键 | 格式约束 | 编码与净化 | 缺失 / 非法时 |

- **发送与接收必须同一个键**：不确定就记 `待定（需一条真机日志对比）`，不假设相等。
- **消息定位键**：撤回 / 去重 / 排序 / 跳转各用哪个键，三处不一致就会错配。
- **URL 拼接**：id 必须 `encode`；允许字符集、空白与控制字符处理各写一句。
- **外部消息体**：接受哪些形态，异常形态是丢弃整条还是降级。
- **缓存 key 组成**：`<域>:<userId>:<id>`，写清跨用户隔离方式。

## 9. 请求预算与缓存生命周期

| 触发点 | 请求数 | 去重键 | 缓存 TTL / 新鲜度 | 清理时机 |

- **谁发起请求**：首次进入 / 列表变化 / 状态变化 / 回前台 / 下拉刷新逐个写。
- **命中缓存是否仍请求**：写死「命中即用」还是「命中仍刷新」；要刷新就写最短间隔与单飞。
- **去重键**：同一对象短时间多次触发用哪个 key 合并。
- **缓存生命周期**：写入时机、过期时间、容量上限、登出 / 切账号 / 提交成功后各清什么。
- **上屏策略**：先缓存后远端时，回包到达前渲染什么，到达后全量重建还是局部更新。

## 10. 等待外部回调的超时与恢复

| 链路 | 等待对象 | 超时阈值 | 超时后状态复原 | 用户可见反馈 |

- 每次「点了之后等别人回」的链路都要一行，只写 HTTP 超时不算。
- **状态复原**：超时后必须在 `finally` 复位「请求中 / 禁用 / 单飞锁」，写完指出复位字段。
- **用户可见反馈**：静默恢复 / toast（文案 key）/ 卡片内错误态，三选一写死。
- **重试与幂等**：超时后重发是否安全（有无幂等键）。

## 11. 新增抽象契约

| 新增的抽象 | 消费者（全部调用点） | 参数是否允许默认值 | 与唯一事实源如何同源 | 越界 / 非法时 |

- **参数默认值**：只有「不存在第二种布局 / 第二种枚举」时才允许默认值；存在第二种形态时禁止默认值。
- **调用点清单列全**：`rg` 出全部引用点写进本表，逐个标「已传 / 待接」。
- **与唯一事实源同源**：写清谁渲染、谁解析、两处读的是不是同一个值。
- **越界处理**：上界、索引、上限这类校验以实际渲染的集合长度为准。
- **实现期新增的文件也算边界**：执行时新起的类 / 文件必须先回文档补一行 `新增` 再写。

## 四类问题清单细则

### 逻辑

必须写清：现状（文件:行号）、改什么、触发入口、数据来源（接口 method + path、请求时机、参数）、字段是新增还是改旧、字段→UI 映射、空数据 / 失败 / 未登录 / 重复点击、缓存与刷新时机、是否影响共用调用点、是否需要实验或灰度。

另外两条最容易漏，必须单独成句：

- **同值重复点击**：点已选项发不发请求、要不要客户端本地拦、拦下来给不给提示。
- **在途竞态**：同一对象「先读后写」时，旧响应能不能覆盖新提交；用请求序号、在途标记还是丢弃过期响应，选一个写死。

### 功能与 UI 的四个常见坑

- **图标拿错**：只允许三种来源——Figma 内图标（node-id）/ 仓库现有 asset 或 iconfont（文件:行）/ 需新增（尺寸、格式、命名）。
- **状态映射错**：一个后端字段的**全部**取值都要有视觉与可点性，不许只写正常态，也不许把未知值兜底成有效态。
- **交互漏写**：元素清单里的元素与矩阵行数必须对得上；弹窗关闭、返回、滚动到底、键盘遮挡、二次确认这类非点击行为也算元素。
- **锚点漂移**：以文案宽度或「内容区」为参照定位的元素（角标、指示条、气泡、分割线）必须写清 en / id 两种文案下的落点，或改成锚图标 / 锚固定坐标。

### 埋点

必须写清：要不要、事件名（沿用还是新增）、上报时机、不报条件（去重 / 二次进入 / 折叠 / 未登录）、参数与取值来源、曝光口径（可见比例 / 停留时长）、上报通道、上报点。版式按 tracking-doc-format。

### 双语

按三类分别列 key，只写第一类就是漏：

1. **后端下发文案**：接口字段名 + 是否随 `locale` 参数变；后端不下发时的兜底。
2. **客户端兜底文案**：本地枚举兜底、空数据、未知值丢弃后的占位、单字段降级默认值——每个兜底分支都要有 key。
3. **错误与提示文案**：网络失败、超时、业务错误码、权限不足、重试按钮各一行。

硬编码禁止：不允许在代码里写 `'Retry'`、`'OK'` 这类裸字符串，兜底文案也走 l10n。

## 宽松问法 → 具体问法

| 别问 | 问这个 |
|---|---|
| 要不要加埋点 | 这个曝光用现有 `xxx` 事件加参数，还是新增事件 |
| 权限要不要置灰 | 次数用尽后还点：静默不响应 / 弹 `xxx` toast / 照发交后端拒 |
| 选中什么效果 | 点击瞬间变色，还是等回包再变色 |
| 枚举会不会新增 | 出现文档外的取值时丢弃还是只读 |
| 接口失败怎么办 | 卡片内错误文案 + Retry（只重拉这张卡），还是整页错误页 |
| 回包缺字段怎么办 | PATCH 只回 `permissions` 不回 `selection` 时保留本地还是清空 |
| 要不要缓存 | 命中缓存还发不发 GET；同一对象 1 秒内 5 次用哪个键合并 |
| 有没有超时 | 等回执最长几秒；超时后哪个字段复位，用户看到什么 |
